# myfirstsite

Sites en scroll construits avec le skill scroll-craft (moteur `scrollcraft.js` / `scrollcraft.css`).

Le skill lui-même est dans `.claude/skills/scroll-craft/` (version 0.3.1, licence MIT, de Nate Herk) : toute session Claude Code ouverte sur ce dépôt le charge automatiquement.

## Voir un site en local

Les vidéos sont chargées par `fetch`, donc il faut un petit serveur, pas un double-clic :

```bash
cd scrollcraft/builds/tenebre      # ou scrollcraft/builds/propagate
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```

## MECHI : à compléter

- **Recevoir les demandes avec Formspree (réglage actuel : `https://formspree.io/f/mwllzzaw`, compte jeudybradley@gmail.com) :** créer un compte gratuit sur formspree.io avec l'adresse Gmail qui doit recevoir les demandes, puis créer un formulaire. Formspree donne une adresse du type `https://formspree.io/f/abcdwxyz` : la mettre dans `FORM_ENDPOINT` en haut de `scrollcraft/builds/mechi/salon.js`. Chaque demande arrive alors par courriel avec toutes les réponses, et « Répondre » répond à la cliente (`_replyto`). Le champ caché anti-robots est envoyé sous le nom `_gotcha`. Le plan gratuit a une limite mensuelle de demandes, à vérifier sur formspree.io. Pour passer le formulaire à Mercedes : soit changer le courriel de réception dans les réglages du formulaire Formspree (rien ne change sur le site), soit lui faire créer son propre compte et remplacer l'adresse dans `FORM_ENDPOINT`.
- **Recevoir les demandes avec FormSubmit (ancien réglage, toujours possible) :** par courriel, à l'adresse inscrite dans `FORM_ENDPOINT` en haut de `scrollcraft/builds/mechi/salon.js` (actuellement jeudybradley@gmail.com). À la toute première demande envoyée depuis le site en ligne, FormSubmit envoie un courriel d'activation : cliquer « Activate Form » une fois. Ensuite, chaque demande arrive en tableau (services, cheveux, souhait, rendez-vous, nom, téléphone, courriel, dépôt accepté), et « Répondre » répond directement à la cliente. L'envoi se fait comme un formulaire ordinaire (sans vérification préalable du navigateur) ; si le navigateur bloque quand même l'envoi, le site passe par la page de FormSubmit et revient avec « Demande envoyée. ». Après l'activation, FormSubmit fournit un alias : le mettre à la place de l'adresse pour la cacher aux robots. La photo d'inspiration n'est plus envoyée par le formulaire : la cliente peut l'envoyer en répondant au courriel du salon.
- **Dépôt Interac :** l'adresse qui reçoit les virements est `INTERAC_EMAIL` en haut de `salon.js` : actuellement jeudybradley@gmail.com. Elle s'affiche dans « Comment ça marche » (étape 3), dans l'encadré du dépôt du formulaire et dans le message « Demande envoyée ». À la remise du site, la remplacer par l'adresse Interac de Mercedes. Activer l'Autodépôt pour cette adresse dans l'application de la banque évite aux clientes la question de sécurité.
- **Règle affichée :** 20 $ déduits de la facture ; gardés si la cliente ne vient pas ou annule moins de 24 h avant. Le site ne peut pas vérifier qu'un virement a été reçu : c'est la propriétaire qui confirme la place à la réception.
- **Services :** six cartes aux coins arrondis (silk press, permanente, teinture, kératine, shampoing traitant, botox capillaire) avec vos photos, « Prix sur devis ». Un clic choisit le service ; il est ajouté à « Ma soumission » et coché dans le formulaire. Les textes sont dans `index.html` et la liste `SERVICES` dans `salon.js`.
