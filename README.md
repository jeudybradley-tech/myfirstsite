# myfirstsite — AI agency website

A one-page website for an AI automation agency. It's plain HTML, CSS and JavaScript, so there's nothing to install or build.

## Files

| File | What it does |
| --- | --- |
| `index.html` | All the page content: hero, services, process, use cases, pricing, FAQ, contact form |
| `styles.css` | The design. Change the colors in `:root` at the top to restyle the whole site |
| `script.js` | Mobile menu, animations, use-case tabs and the contact form |

## Preview it

Open `index.html` in your browser. That's all it takes.

## Make it yours

1. **Name:** replace `Arcline` / `Arcline AI` in `index.html` with your agency's name.
2. **Email:** set `CONTACT_EMAIL` at the top of `script.js` to your email address. The contact form opens the visitor's email app with their message already filled in.
3. **Pricing:** edit the three packages in the `PRICING` section of `index.html`.
4. **Colors:** change `--brand` and `--brand-2` in `styles.css`.

## Put it online (free, with GitHub Pages)

1. Push these files to the `main` branch on GitHub.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, pick **Deploy from a branch**, then select `main` and `/ (root)`, and click **Save**.
4. After a minute, the site is live at `https://<your-username>.github.io/myfirstsite/`.
